# Asset provenance

| Assets | Provenance |
| --- | --- |
| Launcher, splash and Play Store icon | Original artwork supplied by the game owner. Launcher formats use resizing and safe-area padding. |
| World paintings, environment ledges, explorer poses, brush, bee, portal, star and trophy | Original images generated for this project and processed into WebP sprites. |
| Menus, controls and effects | Original gradients, vector drawing, and animation authored in the project. |
| Music and sound effects | Original score and synthesized effects authored for this project. See `tools/synthesize-audio.py` for the compositions and source. |
| Typography | Android system font families. No separate font files included. |

Runtime libraries and the Gradle wrapper retain their upstream licenses. See the AndroidX, Kotlin and Gradle repositories for their license texts.
